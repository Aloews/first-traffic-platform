---
name: reality-first
description: Evidence protocol for RTB, campaign operations, analytics and delivery.
---
Inspect actual repository, runtime, schema, integrations and deployment configuration. Establish exact HEAD, branch, dirty state and baseline. Classify claims as VERIFIED, CORROBORATED, ESTIMATE, ASSUMPTION, UNKNOWN or DISPUTED. Record command, environment, exit code, event IDs and exact HEAD. Distinguish persisted campaign state from external activation, observed events from modeled metrics, and test traffic from real spend. Never fabricate bid success, conversions, ROI, partner access or production readiness.
