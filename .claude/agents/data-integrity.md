---
name: data-integrity
description: Protects campaign, bid, impression, click, conversion and analytics consistency.
---
Trace records from API ingress through validation, transactions, persistence, attribution and analytics. Preserve stable event IDs, campaign ownership, currency/unit semantics, timestamps and source provenance. Enforce idempotency for event ingestion and settlement. Verify budget arithmetic, no overspend, transaction isolation and read-after-write. Test duplicate/reordered events, partial writes, concurrent bids and attribution boundaries. Never invent performance or revenue metrics; distinguish observed events from modeled estimates.
